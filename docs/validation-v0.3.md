# WorkTrace v0.3 验证记录

日期：2026-10-13。验证平台为开发电脑 Windows、Node 22.23.2。所有测试使用合成人员、案件、JSON 和独立临时数据库，TEMP/TMP/TMPDIR 均在 D:\codex+\temp。未运行生产采集或微信，未调用真实模型。

## 新功能验证

- 外部来源适配测试：官方导出形状、非法时间、身份归属、完整分页、体积、幂等与原子拒绝、同步序列及加密 wpack 来源保留。
- 分层检索测试：中文、窗口标题元数据、身份与日期隔离、游标、不匹配窗口继续检索、预算与截断、模型主张边界、候选 stale 状态。
- 候选修订/评估测试：三类独立样例、提炼来源隔离、参考先于输出、最新反馈、候选摘要、幂等历史、失败替换及过期状态；正式修订保留旧/新定义，冲突拒绝，旧回执不回滚。
- 集成测试：本机 API/CLI 导入 → 真实 HTTPS 同步 → MCP stdio 检索和读取 → 加密导出恢复 → 个人总结 → 总控候选 → MCP 记录并查询三类独立样例的离线验收 → 登记修订及重新待评估。

独立代码审查还用 24 种分页参数组合验证同一总结含多候选时无漏项、重复，并核对旧成功状态失效。集成测试发现窗口标题未参与查询，已修复并加入回归。

独立技能前向检查还发现并修正：总控不能直接写入分控案例、工作日与总结形成日查询应分开说明、本地修订文件必须通过正式接口登记后才能绑定验收。旧网络测试固定了 MCP 工具总数，新增工具后已改为检查所需能力存在。
