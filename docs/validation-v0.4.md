# v0.4.0 离线分控实现与验证

本版让员工电脑在总控未上线、不同局域网的情况下独立记录和学习，数日后人工移交统一规范的数据。维护电脑只运行隔离测试，未部署为生产总控或化工员工分控。

## 已实现的链路

| 环节 | 实现与边界 |
|---|---|
| 首次部署 | 正式 Initialize-OfflineNode 入口，匿名下载、发布清单校验、固定 Node 运行时、三个分控 Skill 与 MCP；无需 enrollment、总控证书或局域网发现。首次采集和学习均未启用。 |
| 稳定身份 | role=collector、connection_mode=offline；组织/员工/设备/安装/事件流持久化。重试不改身份、不恢复人工暂停。多台同公司离线节点需显式沿用同一公司 UUID。 |
| 文件版本 | 只读允许目录，稳定两轮后保存；document.version 1.2、SHA256、前一版本、来源路径、解析版本和缺口，原件存在 SQLite。暂停、工作时段或策略变化使在途读取失效。原件与事件事务提交。 |
| 内容边界 | UTF-8/UTF-16LE 文本；DOCX 正文及表内文字；XLSX 单元格、原值和公式缓存。PDF 原件保留但未解析，化学结构图、复杂公式、修订和版式不能宣称理解。单原件最多 20MiB；联网节点最多 4MiB，防止堵塞同步队头。 |
| 本地学习 | 本设备每天一次 source=local 幂等任务，最多三批、每批50条；默认6次/日调用预留、3张必要图片；遵守工作日/时区/学习时段/暂停。只消费新增证据，生成带引用的总结与可重建日报。 |
| 失败处理 | 已尝试而未完成的批次保留检查点，不因重启或次日自动重复调用；明确 retry-local 或暂停后人工复盘。预算耗尽但尚未调用的批次留后续。local任务不污染总控回执或消息。 |
| 完整移交 | SQLite 在线一致快照保留全部表、rowid、队列、未完成批次和文件/截图；流式AES-256-GCM与scrypt加密，清单含哈希、数量、身份、时间和源码版本。上限64GiB，超限拒绝，不截断。 |
| 接收与恢复 | Inspect验证；新总控显式接纳原公司和设备后Import，幂等且跨批冲突整体回滚。Restore为禁止启动的审阅库；Recover只允许原电脑，恢复后采集和学习暂停。原机不自动删数据。 |

完整移交不包含 Codex/GitHub 登录、证书私钥、运行程序及外部模型调试日志。事件、附件、原件、规范化总结及必要运行状态都在数据库；日报由数据库重建。普通 `.wpack` 支持有界证据导出，仍不是全部运行状态的替代品。

## 验证记录

2026-10-13 验证：Node 全量 **101/101通过，0失败、0跳过**；4个维护源Skill格式有效；52个引擎镜像文件逐字节校验通过。Windows离线部署、原联网部署及浏览器回归均通过，自建测试服务已退出。以下不能代替员工电脑验收。

- Node 自动测试：离线建档、重启、文件版本与引用、中文解析、撤销范围、暂停、预算、任务来源隔离、检查点恢复、API/CLI/MCP/HTTPS兼容、加密备份及总控导入。
- 完整包验证：真实大于100MiB的SQLite快照；WAL已提交数据、全部表、未完成任务/批次、原件、截图；错误密码、篡改、冲突及重复导入。
- Windows离线部署：隔离Git-free测试源码包，稳定身份、三技能绑定、默认暂停、冲突与篡改拒绝，停止所有自建服务。此项跳过目标用户MCP注册，不碰既有配置。
- 原联网部署回归：独立总控及两分控测试进程，验证真实Windows活动元数据采样、心跳和同步；正文、截图关闭，不操作微信。
- 浏览器回归：角色与任务界面、暂停恢复、证据回看、导入导出；离线状态明确且隐藏网络同步按钮。
- 真实模型：本机账号一次 gpt-6.1-sol/high 调用，单份合成化工文本原件→本地自动任务→个人总结→日报；没有总控、没有桌面采集。使用12673输入token、999输出token，其中467推理token（CLI返回字段），仅为本样例，不能作为每天固定成本。模型明确识别合成内容、保留未知，没有将测试记录冒充员工技能。

## 员工电脑仍须验收

公司身份、业务软件和目录、真实工作时间必须使用该电脑的实际值。员工账号的模型可用性、MCP发现、真实UIA正文、真实文档保存版本、睡眠/锁屏影响及业务意义，不能由维护电脑的测试代替。合成流程通过只证明技术链路；不证明员工岗位已学会或可以替代人工。

“离线”指不连接公司总控。已启用的被动记录不依赖模型网络，但 Codex 总结仍需员工电脑自己的登录、互联网与额度。记录服务和自动学习有各自暂停状态；异常应保留原始证据和检查点。
